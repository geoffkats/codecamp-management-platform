## How students check in

Students open their attendance page and tap **I'm here – check in** when they arrive, then **Check Out** when they leave. They don't need to type a code.

- Check-in only works during the session time.
- Check-out works after a minimum time on site (normally 60 minutes, 30 for Code Clubs).

## The daily code page

**Attendance Code** (Code Club: **Daily Code**) shows **Today's Attendance Code** and a QR code. Scanning the QR code opens the student check-in page, so students don't have to find it. Use **Print Code** to put it up by the door.

> There is **one code per day for everyone**. **Generate New Code** changes it for every class, so only do it if the code has leaked.

## Mark attendance by hand (Code Camp)

Open **Attendance**:

1. Under **Quick Student Attendance**, filter by **Camp**, **Search Student** or **Filter by Course**.
2. For each student click **Present**, **Late** or **Absent**, or **Mark This Week** / **Mark Last Week**.
3. To mark everyone in the filtered list, use **Mark Filtered Present (This Week / Last Week)**.
4. Further down, choose a date range and click **Export CSV** for records.

## Code Club register

Open **Club Attendance**:

1. Set the **Session Date** and choose the **Club**.
2. Set each member to **Present**, **Late** or **Absent**.
3. Click **Save Attendance**.

If the date isn't one of the club's scheduled days, you'll see a warning. Check the date before saving.
