Use **Lesson Locks** in the sidebar to pace a class: open only today's lesson, or close everything after a session.

1. Choose the course in the **Course** dropdown.
2. The counters at the top show how many lessons are **open** and **locked**.
3. On each lesson row:
   - **Lock** / **Unlock** switches that one lesson.
   - **Only this open** opens this lesson and locks every other lesson in the course. This is perfect for "today we only do Lesson 4".
4. **Unlock all** opens the whole course. **Lock all** closes it (you'll be asked to confirm).

Each row tells you what students see right now: *"Students cannot open this yet"* or *"Students can work on this now"*.

**From the Curriculum builder:** hover a lesson in the left sidebar and click the small **lock** button to lock or unlock it. Locked lessons always show an amber lock, so you can see at a glance what's closed. The course page also marks locked lessons with an amber lock.

> **Important:** locking a lesson here also locks **its quizzes and assignments**. Students can't start a quiz on a locked lesson. The **Locked** switch inside a single quiz (assessment editor) only locks that quiz.

**Empty messages:**
- *"No courses assigned"*: you don't teach any course yet. Ask an admin.
- *"This course has no modules yet."*: build the course first in the Curriculum builder.
