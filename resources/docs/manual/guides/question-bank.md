The **Question Bank** (**Teaching → Question Bank**) holds every reusable question. Write a question once and add it to as many quizzes as you like.

![The Question Bank page](manual:question-bank.png)

The tiles at the top count **All questions**, **Active**, **Drafts**, **Archived** and **Not used yet**. Click a tile to filter the list. Under them you can search, and filter by type, tag, course and difficulty. Each row shows the type, difficulty, tags, points, how many assessments use it, the course and who wrote it.

## Write a question

![The question editor with the student preview](manual:question-editor.png)

1. Click **New question**.
2. Pick the **Question type**: multiple choice, multiple select, true/false, short answer, essay, fill in the blank, matching, ordering, rating, file upload or code submission.
3. Type the **Question**. Code and Scratch scripts are formatted automatically (see *Writing code and Scratch questions*).
4. Add the answers and mark the correct ones.
5. Optional: add an **Explanation shown after answering**.
6. On the right, set **Points**, **Difficulty** (Easy, Medium, Hard), **Status** and **Tags** (separate with commas, e.g. `html, loops`).
7. Under **Belongs to**, click **+ Course** and choose the course (and optionally the module) the question is for. This is how the picker knows which questions belong to your course.
8. Click **Save question**.

> Only **active** questions appear when adding from the bank. Archive old questions instead of deleting them. Past results keep working either way.

## Add bank questions to a quiz

![Adding questions from the bank](manual:question-bank-picker.png)

1. Open the assessment and click **From Question Bank** on the **Questions** tab.
2. The **Questions from** bar starts on **This course: *your course name***, showing only questions that belong to the course you're working in. Switch to **All courses** or **Another course…** if you want to borrow from elsewhere.
3. Narrow the list with search, type, tag and difficulty. **Not used yet** hides questions already used in other assessments.
4. Click **Preview answers** on a row to check it, tick the ones you want (or **Select all**), then add them.

## Finding and tidying questions

On the Question Bank page, each question shows badges such as **Python** or **Scratch blocks** when it contains code. Use the menu on a row to **Duplicate** or **Archive** it, or tick several and use the bulk actions at the bottom.

When a question is used in more than one assessment, the editor warns you: *"Used in N assessments. Your changes apply to all of them."*
