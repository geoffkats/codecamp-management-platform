**What changed:** the page students use to answer quizzes and tests was redesigned to feel like a game.

| Before | Now |
|---|---|
| Small radio buttons in a list | Big red / blue / yellow / green tiles with shapes |
| A plain timer in the corner | A countdown ring that turns red in the last minute |
| Numbers only for navigation | Numbered dots at the bottom, with bookmarks and flags |

**What stays the same:**

- Your questions, points, time limits and attempts are unchanged.
- Answers still save automatically. A "Progress saved" message now confirms it.
- When the time runs out, the quiz is still submitted automatically.

![True/False questions get two big tiles](manual:take-true-false.png)

**Tip for class:** tell students they can press <kbd>1</kbd>–<kbd>4</kbd> to pick an answer and the arrow keys to move between questions.
