- **Scores are always a percentage.** Some pages used to show raw points (e.g. "3") where others showed "75%". Results, submissions and grading now all show the percentage of points available.
- **Saving settings no longer fails.** Saving an assessment's Settings tab could show an error. It now saves and confirms with a message.
- **Old questions display properly.** Questions with code or HTML inside them no longer appear squashed onto one line or partly missing.
