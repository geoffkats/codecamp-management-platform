**What changed:**

- **Teaching → Question Bank** lists every reusable question, with search, type, tag and difficulty filters.
- Each question can have **Tags** (e.g. `loops, variables`) and **Belongs to** one or more courses and modules.
- In an assessment, **From Question Bank** opens a picker that starts on **This course**, so you see the questions for the course you're teaching first. Switch to **All courses** to borrow from elsewhere.
- **Not used yet** hides questions already in other assessments.
- Questions can be **Duplicated** or **Archived** instead of deleted.

![The Question Bank page](manual:question-bank.png)

**Your old questions are safe:** every existing quiz question was kept and is now in the bank as well.
