**What changed:** questions that contain code used to show as one long line of plain text. Now the system recognises code and Scratch scripts and displays them properly everywhere: in the quiz, on the results page, in the editor, in the question bank and when grading.

**Do I need to change my old questions?** No. Existing questions are detected automatically. Open a question and check the **Student preview** under the question text to see how it looks.

**How to write a new one:** put the code or script on its own lines under the question.

```text
What will the sprite do?
when green flag clicked
repeat 4
   move 100 steps
   turn 90 degrees
end
```

Read the full guide for the Scratch typing rules (round numbers, dropdowns, `end`).
