**What changed:** the lesson editor in the Curriculum builder now understands Scratch, just like quiz questions.

**How to use it:**

- **Type it:** write one block per line, starting with `when flag clicked` (or another `when …` block). Press **Enter** after the second line and it becomes a Scratch block with a live preview. Keep typing to add more blocks. Press **Enter** three times to leave the block.
- **Paste it:** pasted Scratch scripts are converted automatically.
- **🧩 Scratch** button: inserts a starter script or converts the selected lines.
- **Detect Scratch** button: converts every Scratch script in an existing lesson in one go.

**What students see:** the script appears as real Scratch blocks on the lesson page. Older lessons with Scratch written as plain lines show as blocks too, without any changes from you.
