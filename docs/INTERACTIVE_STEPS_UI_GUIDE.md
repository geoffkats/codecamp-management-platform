# Interactive Components - Complete Teacher UI Guide

## ✅ What's New

Teachers can now add **3 types of visual components** directly in the curriculum builder - no code required!

1. 📝 **Step-by-Step Instructions** - Numbered visual steps
2. 🎮 **Scratch Project Embed** - Interactive Scratch projects
3. 💻 **Code Examples** - Syntax highlighting for any language

## 📍 How to Use

### Step 1: Go to Curriculum Builder
Navigate to `/curriculum/builder/4` (or your course ID)

### Step 2: Create or Edit a Lesson
- Click "Add Lesson" or edit an existing lesson
- Set **Lesson Type** to "💻 Interactive"

### Step 3: Add Interactive Components
When you select "Interactive" as the lesson type, a new purple section appears: **"Interactive Components"**

You'll see 3 sections (all optional - use what you need):

**1. Step-by-Step Instructions**
```
Step 1: Open your code editor
Step 2: Create a new file called index.html
Step 3: Add the HTML5 template
Step 4: Save and open in browser
```

**2. Scratch Project Embed** (for Scratch lessons only)
```
987654321
```
(Paste the REAL Scratch project ID from your project URL at scratch.mit.edu)

**How to find your Scratch project ID:**
1. Go to your Scratch project: `scratch.mit.edu/projects/987654321`
2. Copy the number from the URL (e.g., 987654321)
3. Paste it in the "Scratch Project Embed" field
4. Don't use placeholder IDs like "1234567890" - they won't work!

**3. Code Examples** (for any programming language)
```
print('Hello World')
name = 'Student'
if age > 18:
    print('Adult')
```

### Step 4: Save the Lesson
Click "Save Lesson" - that's it!

### Step 5: View the Result
Go to `/lessons/{id}/view` to see the beautiful visual steps displayed to students!

## 📝 Writing Steps

You can write steps in any of these formats:

**Format 1: With "Step" prefix**
```
Step 1: Open Scratch
Step 2: Add a sprite
Step 3: Drag motion blocks
```

**Format 2: With numbers**
```
1. Open your Python editor
2. Create a new file
3. Write your first program
```

**Format 3: With dashes**
```
- Install VS Code
- Open a new project
- Start coding
```

**Format 4: Plain text**
```
Open your web browser
Navigate to the website
Click the login button
```

## 🎨 What Students See

When students view the lesson, they'll see:
- ✅ Numbered steps with visual styling
- ✅ Clear, easy-to-follow instructions
- ✅ Professional, engaging layout
- ✅ Works for Scratch, Python, Web Dev, and any topic!

## 💡 Tips

1. **Keep steps short** - One action per step
2. **Be specific** - "Click the green flag" not "Run the program"
3. **Use action verbs** - Start with "Open", "Click", "Type", "Create"
4. **Add context** - Explain why they're doing each step

## 🔄 Editing Steps

To edit steps:
1. Go back to the curriculum builder
2. Edit the lesson
3. The steps will appear in the text box
4. Make your changes
5. Save

## 🚀 Works For All Lesson Types

- **Scratch lessons** - "Add sprite", "Drag blocks", "Test project"
- **Python lessons** - "Open editor", "Write code", "Run program"
- **Web development** - "Create HTML file", "Add CSS", "Test in browser"
- **General lessons** - Any step-by-step instructions!

## ✨ No Code Required!

Teachers just type steps in plain text - the system automatically:
- Converts to proper format
- Adds visual styling
- Numbers the steps
- Displays beautifully to students

That's it! Simple, powerful, and works for everyone.
